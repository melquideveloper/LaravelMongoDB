Para verificar se você tem o Redis instalado e funcionando no seu projeto Laravel em um ambiente Windows, siga os passos abaixo:

✅ 1. Verificar se o Redis está instalado no Windows

No PowerShell (como no seu prompt: PS C:\mongo_laravel\banconosql>), rode:

powershell
redis-cli

Se o comando for reconhecido, você verá um prompt como:

bash
127.0.0.1:6379>

Se der erro como "redis-cli não é reconhecido", o Redis não está instalado corretamente no seu sistema.

✅ 2. Verificar se o Redis está rodando

Ainda no PowerShell:

powershell
Get-Process redis*

Se o Redis estiver rodando, você verá um processo listado. Se não aparecer nada, ele não está em execução.

Você também pode tentar iniciar o Redis manualmente:

powershell
C:\caminho\para\redis-server.exe

Dica: Se você ainda não instalou, baixe o Redis para Windows (não é oficial):
https://github.com/tporadowski/redis/releases

✅ 3. Verificar se o Laravel está configurado para usar Redis

No projeto Laravel (C:\mongo_laravel\banconosql), abra o arquivo .env e veja as seguintes linhas:

env
CACHE_DRIVER=redis
SESSION_DRIVER=redis
QUEUE_CONNECTION=redis

Se estiverem assim, o Laravel está configurado para usar Redis.

✅ 4. Testar o Redis no Laravel

Você pode testar o uso do Redis via Tinker (CLI interativa do Laravel):

bash
php artisan tinker

Depois:

php
Cache::store('redis')->put('teste', 'funciona', 60);
Cache::store('redis')->get('teste');

Se retornar "funciona", está tudo certo 🎉

✅ 5. Verificar se a extensão PHP Redis está instalada

Verifique se o PHP do seu ambiente tem a extensão php_redis.dll habilitada.

No PowerShell:

powershell
php -m | findstr redis

Se aparecer redis, a extensão está habilitada.

Se não, edite o arquivo php.ini e descomente (ou adicione) a linha:

ini
extension=redis
